QuantumForge Semiconductor Modeling, LLC - Static Website

Files included:
- index.html
- services.html
- about.html
- publications.html
- contact.html
- thank-you.html
- styles.css
- assets/quantumforge-background.png

How to use:
1. Edit the page text directly in the HTML files.
2. Edit colors, fonts, spacing, and layout in styles.css.
3. Replace the placeholder email address in contact.html.
4. Create a Formspree account or equivalent managed form service.
5. Replace YOUR-FORMSPREE-ID in contact.html with your real form endpoint.
6. Upload all files and the assets folder to your GitHub Pages repository.

Spam protection:
- The contact form includes a hidden honeypot field.
- For stronger protection, enable CAPTCHA and spam filtering inside Formspree or your chosen form service.
- A static GitHub Pages site cannot send email by itself; the managed form service performs that function.
