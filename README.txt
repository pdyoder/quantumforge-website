QUANTUMFORGE WEBSITE — REPLACEMENT PACKAGE

Installation
1. Back up the current website files.
2. Extract this ZIP on your computer.
3. Upload the HTML files, styles.css, site.js, assets folder, robots.txt,
   and sitemap.xml into the existing website's public root directory.
   Preserve the assets folder and filenames exactly.
4. Replace the corresponding current files when prompted. The existing
   index.html, services.html, about.html, publications.html, and contact.html
   URLs remain available. Three new pages are included: seminars.html,
   expert-witness.html, and advisory.html.
5. Open https://quantumforgesemi.com/ and refresh your browser cache.
   Check navigation, the photograph, and the contact email links.

No build system, external font, subscription, or backend is required.
The site works on conventional static website hosting. To preview locally,
open index.html in a browser, or serve this folder with a local web server.
Do not upload this README or CONTENT-NOTES.txt if you do not want them public.

Contact behavior
The contact form composes an email to qfsm.contact@gmail.com using the
visitor's email application. It does not send or store submissions itself.
Visitors can always use the displayed email address directly. A hosted form
service can be added later if desired; no fake successful-send message is used.

Editing
Edit the HTML files to change copy. Shared styling is in styles.css.
Navigation and footer content appear in every HTML file, so update each
when changing those elements. All image files are included in assets.

Privacy
No analytics, trackers, cookies, remote fonts, or external scripts are added.
No form inputs are persisted by the website. Email is handled by the visitor's
email application/provider after they choose to send.
